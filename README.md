# Brian Kerrigan

I build agentic systems and the instruments that measure whether they work.

Most of my time goes to evaluation methodology: grader instability, construct
validity in automated evaluation, and how a system establishes authority over
decisions derived from interpreted inputs.

### Things here

**[Study-Scout](https://github.com/inspectorSlap/Study-Scout)** — an adversarial
literature review toolkit. Freeze your claims before you search, record every
query and where it came from, keep the rejected candidates with their reasons.
There is deliberately no `NOVEL` verdict in its vocabulary. Python 3.10+,
standard library only, offline demo included.

**[attestations](https://github.com/inspectorSlap/attestations)** — a public
hash and timestamp chain. I work alone, so anything that could later be fitted
to a result gets committed and stamped before the result exists.
